# Kho kiến thức QuanLy One

Đây là nguồn kiến thức dành cho người phát triển và AI sau khi clone repository.
`README.md` hướng dẫn người dùng cài đặt/sử dụng; thư mục này giải thích cách duy
trì và phát triển mã nguồn.

## Chọn tài liệu cần đọc

- `ARCHITECTURE.md`: đọc khi cần hiểu thành phần, đường dẫn, dịch vụ và luồng dữ liệu.
- `DEVELOPMENT.md`: đọc trước khi sửa Web, UI, route, tác vụ nền hoặc triển khai máy test.
- `DATA-SAFETY.md`: bắt buộc khi đụng database, mật khẩu, backup, server game, MOD hoặc thao tác xóa.
- `TESTING.md`: chọn kiểm thử phù hợp với loại file đã sửa.
- `RELEASE.md`: đọc khi đổi phiên bản, tạo tag hoặc GitHub Release.

## Quy tắc duy trì kiến thức

- Khi kiến trúc hoặc quy trình thay đổi, cập nhật đúng tài liệu trong cùng commit.
- Không sao chép nguyên README vào đây; chỉ ghi kiến thức giúp đưa ra quyết định phát triển.
- Ghi trạng thái đang tồn tại, không ghi kế hoạch chưa được triển khai như thể đã có thật.
- Ưu tiên đường dẫn tương đối theo repository; chỉ dùng `/opt/QuanLy_One` cho bản cài runtime chuẩn.
